# Ahmed SEO Website

A simple static business-promotion website for Ahmed SEO.

## Publish for free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. `ahmed-seo`.
3. Upload `index.html`.
4. Open repository Settings → Pages.
5. Choose the main branch/root folder and save.
6. GitHub will provide the live `github.io` website address.

The contact form is intentionally static: it does not store customer data. It opens WhatsApp with a pre-filled message.
